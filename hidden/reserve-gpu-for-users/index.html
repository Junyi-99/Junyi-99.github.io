## Hugging Face Shared Cache Fodler

https://benjijang.com/posts/2024/01/shared-hf-cache/

https://github.com/bstee615/shared-hf-cache

It’s not work in practical.

users /etc/profile is different. it says that editing ~/.bashrc by setting HF_HOME and umask=002 to automatically set the permission of created folder.

However, you can’t ensure the user is using bash or zsh, or changing to fish.

you can’t guarantee the permission is always set.

It always facing the permission error.

I won’t suggest to do this. You can let the user set the cache folder manually, but cannot automatically set the cache folder.

I’m an experienced admin, and I received many complaints of permission errors after setting the shared folder by this blog.

Cons

  1. inconcistant permission
  2. concurrency error.

what should we do?

  1. setting up a shared folder
  2. write a document to let the user manually set the cache folder to the shared folder if they don’t want to download the model.
  3. buy more disks.

## Step 2(/etc/modprob.d/nvidia.conf)

在很多情况下，这两个选项可以同时使用，并且不会冲突。 put the gpus in persistence mode so that the device files are not re-created.

nvidia-persistenced

修改配置文件，让 device file 不重复被创建

#!/bin/bash
options nvidia NVreg_DeviceFileUID=0 NVreg_DeviceFileGID=0 NVreg_DeviceFileMode=0777 NVreg_ModifyDeviceFiles=0

NVreg_ModifyDeviceFiles ensures that driver files are generated once and will not change in the future.

## Step 3 /etc/init.d/gpu-restriction

#!/bin/bash
### BEGIN INIT INFO
# Provides:          gpu-restriction
# Required-Start:    $all
# Required-Stop:
# Default-Start:     2 3 4 5
# Default-Stop:
# Short-Description: Start daemon at boot time
# Description:       Enable service provided by daemon.
#  permissions if needed.
### END INIT INFO
set -e
start() {
/sbin/modprobe --ignore-install nvidia; /sbin/modprobe nvidia_uvm; test -c /dev/nvidia-uvm || mknod -m 777 /dev/nvidia-uvm c $(cat /proc/devices | while read major device; do if [ "$device" == "nvidia-uvm" ]; then echo $major; break; fi ; done) 0 && chown :root /dev/nvidia-uvm; test -c /dev/nvidiactl || mknod -m 777 /dev/nvidiactl c 195 255 && chown :root /dev/nvidiactl; devid=-1; for dev in $(ls -d /sys/bus/pci/devices/*); do vendorid=$(cat $dev/vendor); if [ "$vendorid" == "0x10de" ]; then class=$(cat $dev/class); classid=${class%%00}; if [ "$classid" == "0x0300" -o "$classid" == "0x0302" ]; then devid=$((devid+1)); test -c /dev/nvidia${devid} || mknod -m 660 /dev/nvidia${devid} c 195 ${devid} && chown :nvidia${devid} /dev/nvidia${devid}; fi; fi; done
}
stop() {
:
}
case "$1" in
    start)
       start
       ;;
    stop)
       stop
       ;;
    restart)
       stop
       start
       ;;
    status)
       # code to check status of app comes here 
       # example: status program_name
       ;;
    *)
       echo "Usage: $0 {start|stop|status|restart}"
esac
exit 0
